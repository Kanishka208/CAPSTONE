# AN INTERACTIVE SIMULATION SUITE FOR INSTRUCTION EXECUTION, BUS DESIGN AND ARCHITECTURE PERFORMANCE PROFILING

## Project Overview
This project is an interactive simulation suite designed to visualize instruction execution, bus communication, and architecture performance analysis in Computer Architecture.

## Module 1 – Instruction Execution Simulator
- Instruction decoding
- Register updates
- Memory operations
- Step-by-step execution visualization

## Module 2 – Bus Design Simulator
- Address bus simulation
- Data bus simulation
- Control signal visualization
- Memory transfer operations

## Module 3 – Architecture Performance Profiler
- Benchmark execution
- CPI and execution cycle analysis
- Performance comparison
- Graphical visualization

## Technologies Used
- Python
- Tkinter
- Matplotlib
